# 资产收盘

一个可以添加到 iPhone 主屏幕的资产记录网页。每天手动录入各账户余额，自动计算总资产、日收益和收益率；另有一页记录工资、打工收入。数据只保存在你自己的设备上，不上传任何服务器。

## 先看这三条（很重要）

1. **iPhone 上的主屏幕网页应用和 Safari 是两套独立存储。** 在 Safari 里录入的数据，主屏幕 App 看不到；反过来也一样。请先在 Safari 里“添加到主屏幕”，之后固定从主屏幕图标录入。
2. **删除主屏幕图标会删除这个应用的数据。** 删除前务必先导出备份。
3. **数据只在这台设备上。** 清理网站数据、系统存储压力、换手机都可能丢失记录。请每 1~2 周导出一次 JSON 备份，存到“文件”App 或 iCloud Drive。

## 功能

- **首页**：总资产、日收益、收益率；一键切换“剔除外部收入 / 不剔除”两种口径；30 次记录趋势图。
- **记录**：每天填各账户余额，或只填当天增减；支持资产账户和负债账户（信用卡、花呗）。
- **收入**：记录工资、打工/兼职、奖金等；支持自定义分类；外部转入/转出单独记录。
- **历史**：按月份查看每日记录、区间收益、账户明细；可编辑或删除。
- **设置**：账户管理、分类管理、主题、备份导出/导入、清空数据。
- **离线可用**：添加到主屏幕后，断网也能打开和记录。
- **深色模式**：跟随系统或手动切换。

## 收益怎么算

```text
总资产 = 所有资产账户余额 − 所有负债账户欠款
原始变动 = 本次总资产 − 上次总资产
外部净流入 = 区间内（工资等收入 + 外部转入 − 外部转出），只算“已计入资产”的记录
剔除后变动 = 原始变动 − 外部净流入
收益率 = 变动 ÷ 上次总资产 × 100%
```

区间固定为“上次记录日期的下一天 ~ 本次记录日期”，所以同一笔收入只会被扣除一次。

- **不剔除**：工资到账也会算成收益，收益率会偏高。
- **剔除外部收入**：只反映资产本身的涨跌，更适合看投资/资产表现。
- 首页按钮可以随时切换，两种数字同时计算，不会改变你的数据。

### 什么需要记“外部转入/转出”？

- 账户之间互转（支付宝 → 银行卡）：**不用记**，总资产不变。
- 工资、打工收入：记在收入页，默认勾选“这笔钱已经计入资产账户”。
- 家人转入、借钱给别人、新纳入一个以前就有的账户：记“外部转入/转出”，避免收益虚高或虚低。
- 日常消费：**不用记**，账户余额减少自然会体现出来。

## 每天怎么用

1. 从主屏幕打开“资产收盘”。
2. 点底部“记录”。
3. 默认是“填余额”：自动带入上次余额，只改有变化的数字；没有的账户填 0。
4. 想只填变化，点“填增减”，正数表示增加，负数表示减少（用输入框右侧的 ± 按钮切换）。
5. 点底部“保存”。回到首页就能看到总资产、收益和收益率。
6. 发工资或打工收入时，到“收入”页记一笔。

## 备份与恢复

- **导出**：设置 → 数据与备份 → 导出备份。iPhone 会弹出系统分享面板，选择“存储到文件”，可以存到 iCloud Drive。
- **导入**：设置 → 数据与备份 → 导入备份 → 选择 JSON 文件。导入会覆盖当前全部数据，建议先导出当前备份。
- 导出的文件里包含账户、每日记录、收入、设置。不要手动改金额单位（内部用“分”存储）。

## 部署到 GitHub Pages（用 GitHub Desktop）

1. 没有 GitHub 账号的话，先在 [github.com](https://github.com) 注册并验证邮箱。
2. 安装 [GitHub Desktop](https://desktop.github.com/)，用 GitHub 账号登录。
3. 在 GitHub Desktop 里选择 **File → Add Local Repository**，选中本文件夹。如果提示不是 Git 仓库，选择在这里创建仓库。
4. 仓库名建议 `asset-close`；发布时选择 **Public**（免费版 GitHub Pages 需要公开仓库）。代码公开，但没有任何资产数据。
5. 在 GitHub 网页打开这个仓库 → **Settings → Pages**：
   - Source 选择 **Deploy from a branch**
   - Branch 选择 `main`，目录选择 `/ (root)`
   - 点 Save
6. 等 1~2 分钟，访问 `https://<你的用户名>.github.io/asset-close/`。
7. iPhone 用 **Safari** 打开这个网址 → 分享 → **添加到主屏幕**。

以后更新：GitHub Desktop 里写一句说明 → **Commit to main** → **Push origin**。GitHub Pages 会自动重建；主屏幕 App 在线打开时会提示“有新版本可用”。

> 修改网页文件后，请先把 `sw.js` 里的 `CACHE_NAME` 版本号加一（例如 `asset-close-v1.0.1`），再推送。这样旧缓存会被清理，更新更可靠。

> 国内访问 GitHub Pages 有时较慢。装到主屏幕并完成首次加载后，离线使用不受影响；如果长期无法访问，可以把同一套文件部署到 Cloudflare Pages，代码不需要改。

## 目录结构

```text
index.html                 应用外壳
manifest.webmanifest       PWA 清单
sw.js                      Service Worker（离线缓存）
css/app.css                样式
js/app.js                  路由、主题、导航、更新提示
js/store.js                本地存储、校验、备份导入导出
js/calc.js                 总资产与双口径收益计算（纯函数）
js/utils.js                日期、金额、弹窗、提示
js/chart.js                手写 SVG 折线图
js/views/                  首页、记录、收入、历史、设置
icons/                     主屏幕图标
tools/generate_icons.py    一次性图标生成脚本（Pillow）
tests/                     Node 原生测试
```

## 隐私

- 没有账号、没有后端、没有统计/广告代码。
- 不加载任何外部字体或 CDN。
- 所有数据只写入浏览器的 localStorage。
- 导出的备份文件只在你选择的位置（例如 iCloud Drive）保存。
