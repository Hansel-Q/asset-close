# 资产收盘 v1.1

一个可以添加到 iPhone 主屏幕的资产记录网页。每天手动录入各账户余额，自动计算总资产、收益和收益率。数据只保存在你自己的设备上，不上传任何服务器。

v1.1 起：
- 只有 4 个标签：**首页、记录、历史、设置**。
- 删除了“收入”页和“剔除/不剔除”双口径，统一按总资产变化计算收益。
- 收益为正显示红色、为负显示绿色（A 股习惯）。
- 趋势图可以直接点选某一天看收益。
- 每次保存自动保留本机备份；保存记录后可自动弹出分享面板存到 iCloud Drive。
- 记录页只填余额；点输入框自动清空，不修改会保留上次数字。

## 先看这三条（很重要）

1. **iPhone 上的主屏幕网页应用和 Safari 是两套独立存储。** 在 Safari 里录入的数据，主屏幕 App 看不到；反过来也一样。请先在 Safari 里“添加到主屏幕”，之后固定从主屏幕图标录入。
2. **删除主屏幕图标会删除这个应用的数据**，包括本机自动备份。删除前务必先导出备份。
3. **本机自动备份不是异地备份。** 清理网站数据、换手机、删图标都会丢。请定期用“保存后自动分享”或手动导出，把 JSON 存到“文件”App / iCloud Drive。

## 功能

- **首页**：总资产、收益、收益率；最近记录；可点选的总资产趋势图；备份提醒。
- **记录**：每天填各账户余额，支持资产账户和负债账户（信用卡、花呗）。点击余额输入框会自动清空，直接输入新值；没有点击或点击后没改的账户，保存时保留上次余额。只保留“填余额”，不再有“填增减”。
- **历史**：按月份查看每日记录；趋势图可点击任意记录点，在图表下方查看该日期的总资产、收益和收益率。
- **设置**：账户管理、主题、自动分享开关、本机自动备份（恢复/清空）、手动导出/导入、清空数据。
- **红涨绿跌**：收益和收益率为正显示红色，为负显示绿色；删除/错误/负债等警示仍保持红色，成功状态仍保持绿色。
- **离线可用**：添加到主屏幕后，断网也能打开和记录。
- **深色模式**：跟随系统或手动切换。

## 收益怎么算

```text
总资产 = 所有资产账户余额 − 所有负债账户欠款
收益 = 本次总资产 − 上次总资产
收益率 = 收益 ÷ 上次总资产 × 100%
```

- 只有一种口径，不剔除工资、打工或其它到账资金；工资到账也会计入收益。
- 第一条记录没有上期：只显示总资产，收益/收益率显示“—”。
- 跨多天没记录：显示“区间收益（N 天）”和日均，不把几天的变化伪装成一天。
- 上次总资产 ≤ 0：金额照常显示，收益率显示“—”。

## 每天怎么用

1. 从主屏幕打开“资产收盘”。
2. 点底部“记录”。
3. 页面自动带入上次余额。
   - 点一下某个账户的数字，输入框会自动清空，直接输入新余额；
   - 不想改的账户不要点，或者点了但没输入，离开时会恢复上次数字；
   - 没有的账户填 0。
4. 点底部“保存”。
5. 如果开启了“保存记录后自动弹出备份分享”，会弹出 iPhone 分享面板；选“存储到文件”即可存到 iCloud Drive。
6. 回到首页看总资产、收益和收益率。

## 自动备份与手动备份

### 本机自动备份（最近 7 份）

- 每次保存数据变化后，自动在本机保留一份完整副本；最多保留最近 7 份。
- 设置 → 本机自动备份：可以查看时间、恢复任意一份、清空自动备份。
- “清空全部数据”会先自动备份清空前的状态；自动备份列表会保留，可恢复。
- 只在本机，删除主屏幕图标或清理网站数据会一起丢失。

### 保存后自动分享到 iCloud（可选）

- 设置 → 数据与备份 → “保存记录后自动弹出备份分享”，默认开启。
- 保存一条每日记录后，会自动打开 iPhone 系统分享面板；选“存储到文件”，可以存到 iCloud Drive。
- 如果系统拦截了自动分享，会弹出“自动备份没有弹出”窗口，提供“备份到文件”和“下载备份”。
- 取消分享不会影响已经保存的数据，只是这次没有导出。
- 网页不能静默写入 iCloud，这是苹果的限制；分享面板是可靠的方式。
- 如果觉得每次都弹太频繁，可以在设置里关闭；本机自动备份仍会继续。

### 手动导出 / 导入

- 设置 → 数据与备份 → 导出备份。iPhone 会打开分享面板，选“存储到文件”保存 JSON。
- 设置 → 导入备份 → 选择 JSON。导入会覆盖当前数据；导入前会自动备份当前状态。
- 旧版本（v1.0）备份里的收入数据会在导入时被丢弃（v1.1 已删除收入功能）。
- 清空自动备份是单独操作，不会影响当前账户和记录。

## 数据升级说明

- 从 v1.0 升级到 v1.1 时，应用会自动把本机数据升级到新格式，并**彻底删除旧收入数据**（收入页、收入分类、外部转入转出、双口径设置）。
- 账户、每日记录、主题等非收入数据会保留。
- 以前手工导出过的旧备份文件仍然存在你保存的位置；新版本导入时会自动丢弃其中的收入部分。

## 部署到 GitHub Pages（网页手动上传）

1. 在 [github.com](https://github.com) 创建公开仓库（例如 `asset-close`）。
2. 仓库页面 → **Add file → Upload files**。
3. 打开本文件夹（`资产收盘`），按 **⌘ + A** 全选里面的**内容**（`index.html`、`js`、`css`、`icons` 等），拖进 GitHub 上传区域。不要把外层“资产收盘”文件夹本身拖进去。
4. Commit changes。
5. 仓库 **Settings → Pages**：Source 选 **Deploy from a branch**，Branch 选 `main`，目录选 **/ (root)**，Save。
6. 等 1~2 分钟，访问 `https://<你的用户名>.github.io/asset-close/`。
7. iPhone 用 **Safari** 打开 → 分享 → **添加到主屏幕**。

## 隐私

- 没有账号、没有后端、没有统计/广告代码。
- 不加载任何外部字体或 CDN。
- 所有数据只写入浏览器的 localStorage。
- “保存后自动分享”是由你主动选择保存位置的系统分享面板；应用本身不会把数据上传到任何服务器。
